## 1. 제품 개요

### 1.1 배경 및 목적

포켓몬스터 트레이딩 카드(TCG)는 한국과 일본에서 별도의 유통 구조를 가지며, 동일한 카드라도 국가별로 시세 차이가 크다. 현재 한국판과 일본판 시세를 한 화면에서 비교할 수 있는 전문 서비스가 없어 수집가·투자자들이 여러 플랫폼을 직접 탐색해야 하는 불편함이 있다.

이 사이트는 한국판(KR)과 일본판(JP) 포켓몬 카드 시세를 한 곳에서 조회·비교할 수 있도록 제공하여, 수집가·트레이더·투자자 모두에게 유용한 레퍼런스 플랫폼을 목표로 한다.

### 1.2 제품 목표

| # | 목표 |
|---|------|
| G1 | 한국판 / 일본판 카드 시세를 한 화면에서 비교 제공 |
| G2 | 부스터 박스 단위 시세 조회 및 박스 내 수록 카드 연동 |
| G3 | 가격 추이 그래프로 시세 변동 이력 제공 |
| G4 | 희귀도·가격 기준 정렬 및 이미지 기반 탐색 지원 |
| G5 | 로그인 없이 누구나 무료로 이용 가능 |

## 2. 타겟 유저

|-----------|------|

## 3. 핵심 기능 (Feature List)

### 3.1 카드 시세 조회

- 카드명 텍스트 검색
- 카드 이미지 클릭으로 상세 시세 조회
- 한국판 시세(KRW) / 일본판 시세(JPY → KRW 환산) 동시 표시
- 국가별 시세 출처 링크 제공

### 3.2 부스터 박스 시세 조회

- 발매 세트(팩) 목록 표시
- 박스 단위 시세(한국판 / 일본판) 비교
- 박스 클릭 → 해당 박스 수록 카드 목록 + 개별 카드 시세 연동

### 3.3 정렬 및 필터

- 희귀도(등급) 순 정렬
- 가격 오름차순 / 내림차순 정렬
- 발매 세트별 필터

### 3.4 가격 추이 (히스토리 그래프)

- 카드/박스 개별 페이지에서 기간별 가격 변동 차트 제공
- 한국판·일본판 가격 선을 같은 그래프에 표시

### 3.5 환율 자동 변환

- 일본 엔화(JPY) → 한국 원화(KRW) 자동 환산
- 환율 기준 시각 표시 (예: "2026-07-08 09:00 기준")

### 3.6 데이터 자동 업데이트

- 12시간 간격 자동 크롤링·캐싱
- 마지막 업데이트 시각 UI에 노출

## 4. 데이터 수집 방식

| 국가 | 출처 | 방식 |
|------|------|------|
| 한국판 | 네이버 카페, 당근마켓, 번개장터 | 웹 크롤링 |
| 일본판 | 유유테이(遊遊亭), カードラッシュ, メルカリ 등 | 웹 크롤링 |
| 카드 정보·이미지 | pokemontcg.io (영어 기준) + 자체 DB | API + 크롤링 |
| 환율 | 외부 환율 API (예: ExchangeRate-API) | API |

> **참고**: pokemontcg.io는 영어판(국제판) 카드 기준이므로 카드 이미지·정보 참조용으로 활용하고, 일본판 실제 시세는 일본 중고·판매 사이트 크롤링으로 수집한다.
