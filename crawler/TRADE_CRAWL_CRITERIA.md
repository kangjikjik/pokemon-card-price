# 번개장터 거래 크롤링 기준

## 1. 기본 원칙

- 가격 데이터는 번개장터만 사용한다.
- 최근 90일 이내의 게시글만 수집한다.
- 이미지 비교는 사용하지 않는다.
- 한국판과 일본판 가격을 별도로 집계한다.
- 싱글 카드와 박스 시세를 서로 섞지 않는다.

## 2. 언어 판별

- 제목에 `일판`, `일본판`, `JP`, `Japanese`가 있으면 일본판으로 분류한다.
- 제목에 `한국판`, `한판`, `한국어판`이 있으면 한국판으로 분류한다.
- 언어 표시가 없으면 우선 한국판으로 분류한다.
- 제목에 `북미판`, `북미`, `미국판`, `영문판`, `중판`, `중국판`, `중국어판`이 있으면 한국판 거래에서 제외한다.
- **일본판 가격 하한:** 동일 카드·등급의 한국판 대표 시세가 있으면, 일본판 거래·호가가 한국판보다 **낮으면** 오매칭으로 제외한다. 한국판과 비슷하거나 더 비싼 경우는 정상으로 수집한다.

## 3. 싱글 카드 검색 기준

- 검색 기준은 `카드 이름 + 등급`이다.
- 카드 이름과 등급이 제목에서 확인되어야 한다.
- `ex`는 생략할 수 있다.
  - 예: `메가리자몽 ex MUR`와 `메가리자몽 MUR`은 같은 카드로 인정한다.
- `V`, `VMAX`, `GX` 등은 서로 다른 카드로 취급한다.
- 제목에 다른 카드 이름이 함께 있으면 제외한다.
  - 예: `메가갑주무사, 라이코`
- 검색어별 번개장터 결과는 최대 3페이지, 페이지당 100건까지 조회한다.
- 거래완료 상세 내역은 카드당 최대 100건, 호가 상세 내역은 카드당 최대 100건까지 저장한다.

## 4. 싱글 카드 제외 대상

- `2장`, `3장`, `묶음`, `일괄`, `세트` 등 여러 장을 판매하는 거래
- 구매자가 원하는 카드를 선택하는 거래
- 팩, 박스, 덱, 슬리브, 굿즈 등 싱글 카드가 아닌 상품
- 제목에 `띠부실`, `띠부씰`, `띠부띠부`, `띠부` 등 띠부띠부씰·굿즈 표기가 있으면 제외
- 가격 협의, 나눔, 예약 글
- 북미판·영문판·중판·중국판 등 한국판이 아닌 거래
- `PSA10`, `BRG10` 등 감정·등급 상품
- 카드 이름이나 등급을 확인하기 어려운 글
- 게시일 또는 거래일이 90일을 초과한 글

## 5. 박스 검색 기준

- 검색 기준은 `세트명 + 박스`이다.
- 내부 세트 코드(SM9, MG4a 등)는 번개장터 검색어로 사용하지 않는다.
- 박스 단위 거래만 수집한다.
- 제목에 해당 세트명과 함께 다른 카드 이름이 들어간 거래는 제외한다.
  - 예: `포켓몬 카드 잉어킹 C VMAX라이징`
- 제목에 박스 표기가 없어도 박스 가격대의 매물은 후보로 확인한다.
- 제목에 다른 포켓몬 카드명, 카드번호, 등급, 단품·감정품 표기가 있으면 제외한다.
- `PSA10`, `BRG10` 등 감정·등급 표기가 있으면 제외한다.
- 낱팩, 카드 묶음, 박스 구성품 거래는 제외한다.
- 제목에 `북미판`, `북미`, `미국판`, `영문판`, `중판`, `중국판`, `중국어판`이 있으면 한국판 박스 거래에서 제외한다.
- 박스도 한국판과 일본판을 별도로 집계한다.
- 박스의 거래완료·호가 상세 내역은 지역별로 합산해 최근 30건까지 저장한다.
  - 한국판 박스 최대 30건
  - 일본판 박스 최대 30건
- 박스 단가가 해당 박스의 발매가보다 낮은 거래·호가는 수집하지 않는다.

## 6. 박스 언어 처리

- 제목에 `일판`, `일본판`, `JP`, `Japanese`가 있으면 일본판으로 분류한다.
- 언어 표시가 없으면 한국판으로 분류한다.
- 언어 표시가 없는 거래를 가격만으로 일본판으로 재분류하지 않는다.
- 싱글 카드 가격과 박스 가격은 서로 비교하지 않는다.

## 7. 평균 시세 계산

- 실제 거래 내역과 호가가 모두 있으면 두 가격을 함께 평균 계산한다.
- 실제 거래 내역만 있으면 실제 거래 가격으로 평균을 계산한다.
- 호가만 있으면 호가 가격으로 평균을 계산한다.
- 평균은 상품, 세트, 카드번호, 등급, 언어별로 따로 계산한다.
- 거래완료와 호가를 함께 사용한 경우에도 별도의 `호가 기준` 표시를 하지 않는다.

## 8. 미등록 처리

- 거래와 호가가 모두 없으면 평균값을 0으로 설정한다.
- 거래 목록과 호가 목록을 비워 둔다.
- 상태를 `미등록`으로 표시한다.
- 호가만 있는 상품은 호가 평균을 계산하므로 미등록으로 처리하지 않는다.
- 양수 요약 가격을 저장할 때 같은 수집일의 거래·호가 상세 행이 반드시 존재해야 한다.
- 상세 행이 없는 양수 요약 가격은 저장하지 않고 평균값 0·`미등록`으로 처리한다.

## 9. 이상 가격 제거

- 동일 상품, 등급, 언어의 가격대와 비교한다.
- 실제 거래와 호가를 구분하지 않고 같은 상품·등급·언어 그룹으로 합친다.
- 합친 전체 가격의 중앙값을 기준으로 65% 미만 또는 150% 초과인 가격은 이상치로 제외한다.
- 거래 수가 4건 이상일 때만 이상치로 판정한다.
- 거래 수가 적으면 임의로 삭제하지 않는다.
- 중앙값 밴드(65~150%) 밖 가격은 조건 없이 제외한다.
- SL·PKR 등 기념 세트 등급은 등급별 사전 밴드(예: SL 5,000~500,000원)로 명백한 저가·고가 오매칭을 먼저 제외한 뒤 중앙값 이상치를 적용한다.
- 제외한 거래와 제외 사유를 별도로 기록한다.

## 10. 최종 상태

- `거래·호가 있음`: 실제 거래와 호가를 함께 평균 계산
- `거래 있음`: 실제 거래 가격으로 평균 계산
- `호가만 있음`: 호가 가격으로 평균 계산
- `미등록`: 거래와 호가가 모두 없으며 평균값은 0

## 11. 거래 내역 보존 기간

- 거래 완료·판매중 상세 행의 실제 거래일 또는 게시일이 최근 90일 이내인지 확인한다.
- 90일을 초과한 상세 거래 행은 카드·박스 구분 없이 데이터베이스에서 삭제한다.
- 상세 행의 번개장터 상품 ID와 날짜가 source에 있으면 해당 날짜를 기준으로 판정한다.
- source에 날짜가 없는 기존 상세 행은 `fetched_at`을 기준으로 판정한다.
- 대표 평균 시세 요약 행은 상세 거래 행과 구분하므로 이 정리 작업에서 삭제하지 않는다.

## 12. 상세 내역 없는 가격 처리

- 같은 수집일에 거래 완료 또는 판매중 호가 상세 행이 하나도 없으면 양수 요약 가격을 사용하지 않는다.
- 기존 양수 가격은 데이터베이스에서 0원과 `bunjang:none:no_detail`로 변경한다.
- 0원은 실제 가격이 아니라 미등록 상태를 나타내는 내부 저장값이다.
- 웹사이트에서는 0원을 표시하지 않고 `미등록`으로 표시한다.

## 13. GitHub Actions 일일 증분 크롤

- GitHub Actions 자동 크롤은 매일 한국시간 00:00에 실행한다.
- 실행일의 전날 00:00부터 23:59:59까지 번개장터에 게시·갱신된 거래완료와 호가만 검색한다.
  - 예: 9월 21일 실행분은 9월 20일 거래만 확인한다.
- 기존 데이터베이스의 거래 상세 행은 수정하거나 삭제하지 않는다.
- 전날 새 거래가 확인되면 기존 거래 상세와 새 거래를 합쳐 이상 가격을 다시 판정하고 평균 시세를 재산정한다.
- 전날 새 거래가 없으면 기존 거래 내역과 평균 시세를 그대로 유지한다.
- 새 거래의 PID가 이미 저장되어 있으면 중복 저장하지 않는다.
- 수동 전체 재크롤은 이 증분 규칙과 별도로 실행할 수 있다.

## 14. 스페셜·기념 세트 (CEL / CEL30 / CEL25PK)

### 14.1 싱글 카드 검색

- `CEL`(25주년 기념), `CEL30`(30주년 기념) 카드는 번개장터 검색어에 **기념 접두**를 붙인다.
  - CEL: `25주년` + 카드명 + 등급 (예: `포켓몬카드 25주년 피카츄 V RRR`)
  - CEL30: `30주년` + 카드명 + 등급 (예: `포켓몬카드 30주년 N번 피카츄 PKR`)
- **수집·저장 조건 (한국판·일본판 공통):** 제목에 `25주년`(CEL) 또는 `30주년`(CEL30)이 **반드시** 포함되어야 한다. 접두 없이 카드명·등급만 맞는 다른 팩 매물은 제외한다.
- **일본판(JP):** 검색·저장 모두 `30주년`(또는 `25주년`) + 카드명 + 등급 + `일판`/`일본판` 표기를 사용한다. (예: `30주년 뮤 ex RR 일판`)
- **일본판 가격 하한 (KR 대비):** 동일 카드·등급의 한국판 대표 시세가 있으면, 일본판 거래·호가가 **한국판보다 낮으면** 오매칭으로 제외한다. 한국판과 비슷하거나 더 비싼 경우는 정상으로 수집한다. (기념 SL 등 대부분의 일판은 한국판보다 비싼 편이다.)
- **30주년 PKR 피카츄(1~30번):** DB명은 `N번 피카츄`이지만 번개 표기는 `피카츄 N번`이 많다. 검색·제목 매칭 모두 `30주년 피카츄 N번` 형식을 인정한다.
- **30주년 SL(Shining)만 예외:** 다른 등급과 달리 제목에 `SL`·등급 표기가 없어도 수집한다. 검색어는 `30주년 복각 + 포켓몬 이름`을 사용한다 (`SL` 접미사 금지). **한국판·일본판 모두** 제목에 `30주년` + 카드명 + **`복각`**이 있어야 한다. 복각 없는 구세트·오매칭은 제외한다.
- SL 검색(`30주년 + 이름`) 결과에 띠부띠부씰·굿즈 매물이 섞일 수 있으므로 §4 띠부실 제외 규칙을 반드시 적용한다.
- 세트명·등급·카드명이 제목에서 확인되어야 하며, 일반 싱글 카드 제외 규칙(§4)을 동일하게 적용한다.

### 14.2 박스 검색

- `CEL` 박스: `25주년 기념 박스`, `25주년 컬렉션 박스` 등 **25주년 + 박스** 표기로 검색한다.
- `CEL30` 박스: `30주년 기념 박스`, `30주년 박스` 등 **30주년 + 박스** 표기로 검색한다.
- 내부 코드(`CEL`, `CEL30`)는 검색어로 쓰지 않는다.
- 박스 제외·언어·이상 가격 규칙(§5~§9)은 일반 확장팩과 동일하다.

### 14.3 25주년 프로모팩 (CEL25PK) — 낱팩 1장 시세

- `CEL25PK`는 **박스가 아니라 프로모팩 1팩** 단위 시세를 수집한다.
- 검색 예: `25주년 프로모팩`, `25주년 기념 프로모팩`, `포켓몬카드 s8aP`
- 박스·다팩 묶음·싱글 카드·박스 구성품 거래는 제외한다.
- 팩 2장 이상 묶음은 단가로 환산해 1팩 가격대인지 확인한다.
- P 등급 카드 시세는 `crawl_promo_prices.py`로 별도 수집한다.
